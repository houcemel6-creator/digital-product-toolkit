# Product Pricing Calculator

A free, open-source browser calculator for handmade and digital-product sellers. Estimate a selling price from production costs, labor, other expenses, percentage fees, a fixed per-sale fee, and a target profit margin.

## Use it

Open `index.html` in a modern browser. No installation or account is needed. Enter costs and fee details in your own currency. The optional selling-price field estimates profit at a price you choose.

## Pricing method

`Suggested price = (total costs + fixed per-sale fee) / (1 - percentage fee rate - target profit margin rate)`

The percentage fee and target margin must add up to less than 100%. Estimates depend on the values entered; check the current fee rules for your platform and include all relevant costs.

## Privacy

Calculations happen in your browser. This project has no server, cookies, analytics, or external dependencies, and it does not send entered amounts anywhere.
